# Image Optimizer

- 관리자 페이지에 게시된 고용량 원본 이미지의 픽셀 크기와 용량을 함께 줄이는 스크립트입니다.
- **폴더와 대상 요소의 가로·세로** 값을 지정해서 실행합니다.
- 원본은 건드리지 않고, 파일명·확장자·폴더 구조도 그대로 유지합니다.
- FTP에 다시 올릴 때는 `images-optimized` 폴더의 결과만 사용합니다.

## 1. 준비

Node.js 18 이상이 필요합니다.

```bash
npm install
```

원본은 `images` 폴더 아래에 기존 폴더 구조 그대로 넣습니다.

```text
images/
└─ notice_01/
   └─ 2026_02_13/
      └─ photo.jpg
```

## 2. 실행

- 대상 요소의 가로·세로 사이즈를 넣습니다.
- 폴더는 `images` 기준 경로입니다.
- 결과는 `images-optimized` 아래 동일한 경로로 저장됩니다.

```bash
npm start -- notice_01 300:300
npm start -- banners 1920:600
```

```text
images/notice_01/2026_02_13/photo.jpg
  → images-optimized/notice_01/2026_02_13/photo.jpg
```

- 폴더 구조, 파일명, 확장자는 바뀌지 않습니다. FTP에 올릴 때 기존 경로를 그대로 쓰면 됩니다.
- 같은 폴더를 다시 실행하면 **해당 결과 폴더를 지우고, 원본 기준으로 다시** 만듭니다.
- 이미 줄어든 파일을 재압축하지는 않습니다.

## 3. 어떻게 줄이나

- 파일을 자르지 않고 원본 비율을 유지한 채 지정한 사이즈로 리사이즈됩니다.
- 넣은 `가로:세로` 값은 화면 요소 크기입니다. 요소의 가로·세로를 모두 채울 수 있는 크기로, 비율을 유지한 채 한 번에 줄입니다. 한쪽은 요소와 같고, 다른 쪽은 비율 때문에 더 깁니다.
  - `300:300` + `2500×1500`(가로가 더 김) → `500×300`  
    세로는 300, 가로는 더 김
  - `300:300` + `1856×2304`(세로가 더 김) → `300×372`  
    가로는 300, 세로는 더 김
  - `1920:600` + `4000×2000` → `1920×960`  
    가로는 1920, 세로는 더 김
- 결과 파일은 요소보다 한쪽이 더 길 수 있습니다.
- 페이지에서 `object-fit: cover`를 쓰면 칸이 꽉 차고, 파일에는 구도 전체가 남아 있습니다.
- JPG/WebP는 품질 82로 압축하고, PNG는 포맷을 유지한 채 압축합니다.
- JPG / JPEG / PNG / WebP만 최적화합니다. GIF 등 나머지는 그대로 복사합니다.

## 4. 사용할 때

- FTP에 올리기 전에 원본을 백업하고, 결과 이미지를 몇 장 열어 확인합니다.
- PNG는 JPG만큼 용량이 안 줄어들 수 있습니다. 확장자는 바꾸지 않습니다.
- `images-optimized`는 다시 실행하면 지워지므로, 여기에 따로 파일을 두지 않습니다.
