# Image Optimizer

- 관리자 페이지에 게시된 고용량 원본 이미지의 픽셀 크기와 용량을 함께 줄이는 스크립트입니다.
- **폴더와 목표 사이즈만 지정**해서 실행합니다.
- 원본은 건드리지 않고, 파일명·확장자·폴더 구조는 그대로 둡니다.
- FTP에 다시 올릴 때는 `images-optimized` 결과만 사용합니다.

## 1. 준비

Node.js 18 이상이 필요합니다.

```bash
npm install
```

원본은 `images` 아래에 기존 폴더 구조 그대로 넣습니다.

```text
images/
└─ notice_01/
   └─ 2026_02_13/
      └─ photo.jpg
```

## 2. 실행

```bash
npm start -- <폴더> <가로:세로> # 390:290
npm start -- <폴더> <가로> # 정사각이면 가로만 입력해도 됩니다. (ex: 300*300 → 300)
```

```bash
npm start -- notice_01 280
npm start -- notice_01/2026_02_13 280:280
npm start -- banners 1920:600
```

`폴더`는 `images` 기준 경로입니다. 결과는 `images-optimized` 아래 동일한 경로로 저장됩니다.

```text
images/notice_01/2026_02_13/photo.jpg
  → images-optimized/notice_01/2026_02_13/photo.jpg
```

폴더 구조, 파일명, 확장자는 바뀌지 않습니다. FTP에 올릴 때 기존 경로를 그대로 쓰면 됩니다.

같은 폴더를 다시 실행하면 해당 결과 폴더를 지우고, **원본 기준으로 다시** 만듭니다.

이미 줄어든 파일을 재압축하지는 않습니다.

## 3. 어떻게 줄이나

지정한 사이즈에 CSS `object-fit: cover`처럼 맞춥니다.

1. 비율을 유지한 채 이미지 **전체를 축소**합니다. 원본 왼쪽 위를 그대로 잘라내지 않습니다.
2. 비율이 다르면 넘치는 부분만 **가운데 기준**으로 자릅니다.
3. JPG/WebP는 품질 82로 압축하고, PNG는 포맷을 유지한 채 압축합니다.

예: `2500×1500`을 `300×300`으로 지정하면 `500×300`으로 줄인 뒤, 가운데 `300×300`만 남깁니다.

JPG / JPEG / PNG / WebP만 최적화합니다. GIF 등 나머지는 그대로 복사합니다.

## 4. 사용할 때

- FTP에 올리기 전에 원본을 백업하고, 결과 이미지를 몇 장 열어 확인합니다.
- PNG는 JPG만큼 용량이 안 줄어들 수 있습니다. 확장자는 바꾸지 않습니다.
- `images-optimized`는 다시 실행하면 지워지므로, 여기에 따로 파일을 두지 않습니다.
